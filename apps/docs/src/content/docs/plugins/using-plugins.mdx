Everything in Basics and Composition (values, validation, submission, reusable field components, and fieldsets) comes from the core. Everything else is opt-in plugins. Each plugin adds capabilities to your form, like `dirty` tracking on fields or `form.plugins.history.undo()`, and if you don't install a plugin, none of its code ends up in your bundle.

## Where to install plugins

You can install plugins at three levels depending on how widely you need them:

- **On `createForms`** to share them across every form in your app.
- **On `forms.define`** to enable them for a specific form definition.
- **On `useForm` / `createForm`** for a single form instance (read once on mount; runs after shared and definition plugins).

```ts
const forms = createForms({ plugins: [dirty()] });

const settings = forms.define({ defaultValues, plugins: [history()] });
```

```tsx framework=react
const form = useForm(signUp, { plugins: [persist("sign-up")] });
```

```tsx framework=solid
const form = createForm(signUp, { plugins: [persist("sign-up")] });
```

## Catching missing plugins at compile time

If you use a feature or component that depends on a plugin your form hasn't installed, TypeScript catches it and tells you what to add:

```text
Add limit() to this form's plugins: ShortNote uses it
```

That same check protects field types carrying a plugin [part](../writing-plugins/parts), array commands like `push` without `arrays()`, and `equals` without `dirty()`. If untyped code calls a missing plugin anyway, development builds throw a runtime error (such as [`dirty:missing`](/errors#core:dirty:missing)).

## Where plugins live

| Kind | External dependencies | Where to import from |
| --- | --- | --- |
| First-class | None | Your adapter's `/plugins` entry (e.g. `@lunarhue/forms-react/plugins`) |
| Third-party | Yes | Its dedicated package, like `@lunarhue/forms-schema/zod` |
| Community | Depends on the plugin | The author's package, conventionally `forms-plugin-<name>` |

All first-class plugins (`arrays`, `dirty`, `baselineOnSubmit`, `rebase`, `persist`, `history`, `rules`, and `bind`) live in `@lunarhue/forms-core/plugins` and are re-exported from each framework adapter's `/plugins` entry. [Schema plugins](./schemas) live in `@lunarhue/forms-schema`, external store bindings live in `@lunarhue/forms-bind`, the live inspector lives in [`@lunarhue/forms-devtools`](./devtools), and [Masks](./masks) are standalone parts from `/text` that don't require a plugin.

Want to build your own? Head over to [Writing plugins](../writing-plugins/first-plugin).
