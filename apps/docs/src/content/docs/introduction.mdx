`@lunarhue/forms` splits form handling into two layers: a small, framework-agnostic core that manages values, validation, errors, and submission state, and a thin adapter (`@lunarhue/forms-react` or `@lunarhue/forms-solid`, with Vue planned) that connects that state to your components.

Validation is built into the core. Everything else (dynamic arrays, dirty tracking, undo/redo history, persistence, schema defaults, conditional rules) ships as opt-in plugins from a single `plugins` entry point. Text formatting and input masks live in the `text` entry and attach directly to individual fields without needing a plugin. Because nothing is wired in until you import it, your bundle only pays for the features you use.

Everything is typed from the start. Your form's type comes straight from `defaultValues`, so TypeScript catches typos in field names before you even save the file:

```tsx framework=react
const signUp = createForms().define({
  defaultValues: { name: "", email: "" },
  onSubmit: (value) => save(value),
});

function SignUpForm() {
  const form = useForm(signUp);
  return (
    <form {...form.formProps}>
      <form.Field name="name">{(field) => <input {...inputProps(field)} />}</form.Field>
      {/* Type error: "emial" is not a field of signUp. */}
      <form.Field name="emial">{(field) => <input {...inputProps(field)} />}</form.Field>
    </form>
  );
}
```
