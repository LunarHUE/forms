## Make a forms object

`createForms` holds what your forms share: plugins, field components and
settings. This form needs none of them.

```ts title="sign-up.tsx" framework=react
import { createForms } from "@lunarhue/forms-react";

const forms = createForms();
```

```ts title="sign-up.tsx" framework=solid
import { createForms } from "@lunarhue/forms-solid";

const forms = createForms();
```

## Define the form

```ts title="sign-up.tsx"
const signUp = forms.define({
  defaultValues: { name: "", email: "" },
  onSubmit: (value) => `Signed up ${value.name}.`,
});
```

`defaultValues` is the value the form starts from, and its type is the form's
type. Here that is `{ name: string; email: string }`. `onSubmit` gets a copy
of the value when the user submits.

## Render it

<Only framework="react">

`useForm` makes a form from the definition for this component.

```tsx title="sign-up.tsx"
import { inputProps, useForm } from "@lunarhue/forms-react";

export default function SignUpForm() {
  const form = useForm(signUp);
  return (
    <form.Form>
      {(formProps) => (
        <form {...formProps}>
          <form.Field name="name">
            {(field) => (
              <label>
                Name
                <input {...inputProps(field)} />
              </label>
            )}
          </form.Field>
          <form.Field name="email">
            {(field) => (
              <label>
                Email
                <input {...inputProps(field, { type: "email" })} />
              </label>
            )}
          </form.Field>
          <button type="submit">Sign up</button>
        </form>
      )}
    </form.Form>
  );
}
```

</Only>

<Only framework="solid">

`createForm` makes a form from the definition for this component.

```tsx title="sign-up.tsx"
import { createForm, inputProps } from "@lunarhue/forms-solid";

export default function SignUpForm() {
  const form = createForm(signUp);
  return (
    <form.Form>
      {(formProps) => (
        <form {...formProps}>
          <form.Field name="name">
            {(field) => (
              <label>
                Name
                <input {...inputProps(field)} />
              </label>
            )}
          </form.Field>
          <form.Field name="email">
            {(field) => (
              <label>
                Email
                <input {...inputProps(field, { type: "email" })} />
              </label>
            )}
          </form.Field>
          <button type="submit">Sign up</button>
        </form>
      )}
    </form.Form>
  );
}
```

</Only>

- `form.Form` hands your `<form>` its submit handler as `formProps`, and turns
  off the browser's own validation.
- `form.Field` takes a field name and passes that field to its child. The
  compiler checks the name, so `name="emial"` is a type error.
- `inputProps(field)` gives the input its value, `name`, `id`, the change and
  blur handlers, and the aria attributes for errors.

## Show the result

Whatever `onSubmit` returns becomes `submission.result`. Read it from the
form's state:

```tsx framework=react
<form.State select={(state) => state.submission}>
  {(submission) => (
    <p role="status">{submission.status === "succeeded" ? submission.result : null}</p>
  )}
</form.State>
```

```tsx framework=solid
<p role="status">
  <Show when={form.state.submission.status === "succeeded" && form.state.submission}>
    {(submission) => submission().result}
  </Show>
</p>
```

<Only framework="react">

`form.State` re-renders only its children, and only when the selected value
changes.

</Only>

<Only framework="solid">

`form.state` is reactive, so only this text updates.

</Only>

A submission is `idle`, `submitting`, `invalid`, `failed` or `succeeded`. If
`onSubmit` throws, the status is `failed` and `error` holds what it threw.
[Submit](./submit) has the rest.
