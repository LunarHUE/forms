## 1. Create a forms instance

Start by calling `createForms()`. This object holds whatever your forms share: plugins, reusable field components, and default settings. For now, an empty call is all we need.

```ts title="sign-up.tsx" framework=react
import { createForms } from "@lunarhue/forms-react";

const forms = createForms();
```

```ts title="sign-up.tsx" framework=solid
import { createForms } from "@lunarhue/forms-solid";

const forms = createForms();
```

## 2. Define the form

Next, describe the form's shape and submit handler with `forms.define()`. Defining forms outside your component keeps them reusable and separates form logic from rendering.

```ts title="sign-up.tsx"
const signUp = forms.define({
  defaultValues: { name: "", email: "" },
  onSubmit: (value) => `Signed up ${value.name}.`,
});
```

`defaultValues` sets the starting values for every field, and TypeScript infers the form's value type (`{ name: string; email: string }`) from it. When the user submits, `onSubmit` receives a fresh copy of those values.

## 3. Render the form

<Only framework="react">

Inside your component, pass the definition to `useForm` to create a live form instance:

```tsx title="sign-up.tsx"
import { inputProps, useForm } from "@lunarhue/forms-react";

export default function SignUpForm() {
  const form = useForm(signUp);
  return (
    <form {...form.formProps}>
      <form.Field name="name">
        {(field) => (
          <label>
            Name
            <input {...inputProps(field)} />
          </label>
        )}
      </form.Field>
      <form.Field name="email">
        {(field) => (
          <label>
            Email
            <input {...inputProps(field, { type: "email" })} />
          </label>
        )}
      </form.Field>
      <button type="submit">Sign up</button>
    </form>
  );
}
```

</Only>

<Only framework="solid">

Inside your component, pass the definition to `createForm` to create a live form instance:

```tsx title="sign-up.tsx"
import { createForm, inputProps } from "@lunarhue/forms-solid";

export default function SignUpForm() {
  const form = createForm(signUp);
  return (
    <form {...form.formProps}>
      <form.Field name="name">
        {(field) => (
          <label>
            Name
            <input {...inputProps(field)} />
          </label>
        )}
      </form.Field>
      <form.Field name="email">
        {(field) => (
          <label>
            Email
            <input {...inputProps(field, { type: "email" })} />
          </label>
        )}
      </form.Field>
      <button type="submit">Sign up</button>
    </form>
  );
}
```

</Only>

Here is what each piece does:

- **`form.formProps`** hooks up the `<form>`'s `onSubmit` handler and sets `noValidate` so the browser's built-in popups don't fight with your own error UI.
- **`form.Field`** subscribes to a single field by name and passes its state to your render function. Because field names are type-checked against `defaultValues`, a typo like `name="emial"` fails at compile time.
- **`inputProps(field)`** wires up the standard `<input>` attributes for you: `value`, `name`, `id`, change and blur handlers, `ref`, and ARIA error attributes.

## 4. Show the submit result

Anything you return from `onSubmit` becomes `submission.result` on the form's state. Render it right below the button:

```tsx framework=react
<form.State select={(state) => state.submission}>
  {(submission) => (
    <p role="status">{submission.status === "succeeded" ? submission.result : null}</p>
  )}
</form.State>
```

```tsx framework=solid
<p role="status">
  <Show when={form.state.submission.status === "succeeded" && form.state.submission}>
    {(submission) => submission().result}
  </Show>
</p>
```

<Only framework="react">

`form.State` only re-renders its children, and only when the selected `submission` value changes.

</Only>

<Only framework="solid">

Because `form.state` is fine-grained reactive, only that text node updates when the submission changes.

</Only>

A submission can be `"idle"`, `"submitting"`, `"invalid"`, `"failed"`, or `"succeeded"`. If `onSubmit` throws, the status becomes `"failed"` and `submission.error` holds whatever was thrown. We cover the full lifecycle on the [Submit](./submit) page.
