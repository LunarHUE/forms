Every `name` prop is type-checked against your form's value type. Misspell a path or wire a text input to a number field, and TypeScript catches it at build time. When you want to pass a slice of a form down to another component, use a **handle**: a lightweight, typed reference to a single field.

<Demo name="typed-paths/shipping" />

## Dotted field names

For nested objects, `name` uses dot notation like `"shipping.city"`. Type a typo into the form above and TypeScript points you to the valid paths:

```tsx framework=react
<form.TextField name="shipping.cty" label="City" />
```

```tsx framework=solid
<form.TextField name="shipping.cty" label="City" />
```

```text
error TS2769: No overload matches this call.
  ...
    Type '"shipping.cty"' is not assignable to type '"billing.street"
    | "billing.city" | "shipping.street" | "shipping.city"'.
    Did you mean '"shipping.city"'?
```

Notice that `"shipping"` isn't in that list: even though it's a valid path in the form, its value is an object, and `TextField` expects `FieldApi<string>`.

Dotted names walk through nested objects (up to 8 segments deep) and stop at arrays. You can reference `"tasks"`, for example, but not `"tasks.0.title"`. Individual array rows are accessed through handles instead; see [Arrays](../plugins/arrays).

## Working with handles

`form.root` is the handle for the whole form value. Call `.at(key)` to step down into any child field, with autocomplete and typo checking along the way:

```ts
const shipping = form.root.at("shipping"); // handle to { street, city }
const city = shipping.at("city"); // handle to a string

form.root.at("shiping");
// Argument of type '"shiping"' is not assignable to parameter of type
// '"billing" | "shipping"'.
```

A handle holds no state itself; calling `.at("city")` always returns the same stable object reference. It carries the field's commands (`setValue`, `reset`, `validate`, and array methods like `push`), plus `peek()` for reading the current snapshot inside event handlers without subscribing.

You can pass a handle directly to any field component via the `handle` prop instead of `name`:

```tsx framework=react
<form.TextField handle={form.root.at("shipping").at("city")} label="City" />
```

```tsx framework=solid
<form.TextField handle={form.root.at("shipping").at("city")} label="City" />
```

<Only framework="react">

To subscribe to a handle's state directly in a component, call `useField(handle)` (or `useField(handle, select)` to only re-render when a specific slice changes). `useField(handle)` returns the same `FieldApi` object as `form.Field`, so `inputProps(useField(handle))` works directly.

</Only>

<Only framework="solid">

To read a handle's state reactively in a component, call `createField(handle)`. All of its properties are reactive getters.

</Only>
